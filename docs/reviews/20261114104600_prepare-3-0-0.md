## Decisions

- Cut source for 3.0.0 is main after RFC-0008 through RFC-0011 (Delivery,
  integer signals, expiration hygiene, catalogue export).
- Version is 3.0.0 because `expires_at` no longer gates visibility, variants,
  Delivery routing, or evaluation statistics; hosts that stopped rollout via
  expiry must call `park!`.
- Accept pre-existing LOC warnings above the soft 150-line target for
  `app/admin/features.rb`, `lib/onni.rb`, and `usr/lib/release_version_check.rb`
  (all below the hard failure ceiling). Keep `make bench-gate` as the publish
  resource check for the all-features probe; Delivery pressure gates remain in
  `benchmarks/delivery_*`.
- Deliver stays separate: after the cut commit on main, run `make release`.
