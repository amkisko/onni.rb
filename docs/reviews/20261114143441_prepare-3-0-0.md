# Prepare onni 3.0.0 (revised)

## Participants

Andrei Makarov.

## Decisions

- Cut source for 3.0.0 is main after RFC-0008 through RFC-0012 (Delivery,
  integer signals, expiration hygiene, catalogue export, optional ActiveAdmin
  GraphQL operator API).
- Version stays 3.0.0. The earlier same-day cut was never tagged or published
  to RubyGems; revise that unpublished payload instead of opening 3.1.0.
- Version remains major because `expires_at` no longer gates visibility,
  variants, Delivery routing, or evaluation statistics; hosts that stopped
  rollout via expiry must call `park!`.
- Accept pre-existing LOC warnings above the soft 150-line target for
  `app/admin/features.rb`, `lib/onni.rb`, and `usr/lib/release_version_check.rb`
  (all below the hard failure ceiling). Keep `make bench-gate` as the publish
  resource check for the all-features probe; Delivery and agent-access gates
  remain in their benchmark files.
- Deliver stays separate: after the cut commit on main, run `make release`.
