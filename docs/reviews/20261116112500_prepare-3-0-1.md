# Prepare onni 3.0.1

## Participants

Andrei Makarov.

## Decisions

- Cut source for 3.0.1 is main after ActiveAdmin host DX collected since 3.0.0:
  packaged agent-access guide and scope mapping, zero Onni `routes.rb` lines
  for Features, optional vanity draw hardening, and Delivery on the Features
  Assignment label.
- Version is patch because public evaluation and Delivery contracts stay
  compatible.
- Keep product-facing `CHANGELOG.md` free of other product names. Browser
  system coverage stays maintainer-only (`CONTRIBUTING.md` and
  `PlaywrightEnv`); omit it from release notes.
- System examples skip when the browser CLI or Chromium tree is missing, so a
  redirected empty browser cache does not fail the suite.
- Accept pre-existing LOC warnings above the soft 150-line target for
  `app/admin/features.rb`, `lib/onni.rb`, and `usr/lib/release_version_check.rb`
  (all below the hard failure ceiling). Accept AbcSize refactor notices for
  `ActiveAdminRoutes.draw` and `Access.map_capabilities` (rubocop exit 0).
- Deliver stays separate: after the cut commit on main, run `make release`.
