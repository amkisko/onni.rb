# Release 2.0.0

## Participants

Andrei Makarov (@amkisko).

## Decisions

Cut gem 2.0.0 from main for audience filter composition (RFC-0005),
evaluation statistics policy (RFC-0006), programmatic definitions
(RFC-0007), and the RSpec install reset qualification. Use 2.0.0 because
ordinary YAML audience types become filters and experiments need an
explicit audience. Accept the memory-adapter aggregate timing and
pre-existing source-size findings for this cut; the delivery gate
(`make bench-gate`) stays the publish check. Keep prepare and deliver
distinct: this note records the cut; `make release` publishes.

## Effects

- `lib/onni/version.rb` -> 2.0.0
- `CHANGELOG.md` moves Unreleased bullets under `## 2.0.0 (2026-11-13)`
- Path gem locks refresh to 2.0.0

## Next

1. Commit the cut on main.
2. Run `make release` for RubyGems push, git tag, and GitHub release.
3. Hosts migrate YAML and call sites from exclusive audience types to
   filters before or with the upgrade; drop any manual
   `Onni::RSpec.reset!` before-hook workaround after upgrade.
