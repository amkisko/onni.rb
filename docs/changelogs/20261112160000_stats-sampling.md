# Stats sampling controls

## Participants

Andrei Makarov (@amkisko)

## Decisions

Ship clamped sample rates, optional sampler callable, ignore list, and optional inverse-rate weighting of kept samples for hit counters.

## Effects

- `Onni::Stats::Sampler` owns the keep/skip/weight decision.
- Adapters accept `weight:` on `record_stat`.
- README documents sampling configuration.
- Specs cover clamp, ignore, sampler, scale on/off, and AR weighted upsert.
