# Release 3.0.0

## Participants

Andrei Makarov.

## Decisions

Cut gem 3.0.0 from main for Delivery experiments (RFC-0010), integer signals
(RFC-0009), expiration hygiene (RFC-0008), catalogue export (RFC-0011), and the
optional ActiveAdmin GraphQL operator API (RFC-0012). Use 3.0.0 because
`expires_at` no longer gates visibility, variants, Delivery routing, or
evaluation statistics; hosts that stopped rollout via expiry must call `park!`.
Revise the unpublished cut to include RFC-0012: 3.0.0 was prepared earlier the
same day and never tagged or pushed to RubyGems. Keep prepare and deliver
distinct: this note records the cut; `make release` publishes.

## Effects

- `lib/onni/version.rb` -> 3.0.0
- `CHANGELOG.md` moves Unreleased bullets under `## 3.0.0 (2026-11-14)`,
  including GraphQL operator bullets after the Delivery cut
- Path gem locks refresh to 3.0.0
- Optional `onni/active_admin_graphql` ships in the gem; GraphQL and device
  authorization stay development/test dependencies

## Next

1. Commit the revised cut on main.
2. Run `make release` for RubyGems push, git tag, and GitHub release.
3. Hosts that relied on expiry to stop rollout must park overdue flags before
   or with the upgrade; add `Onni.verify_expirations!` where catalogue hygiene
   belongs in specs or CI.
4. Hosts that adopt the GraphQL operator surface configure real authentication,
   consent, trusted origin, rate limits, and token secret storage.
