## Decisions

Cut gem 3.0.2 from main for the GraphQL security floor collected after 3.0.1
and the iterative audit repairs on stats purge, warning delivery, catalogue
export reads, and hot-path allocation work. Use patch because public evaluation
and Delivery contracts stay compatible. Keep prepare and deliver distinct: this
note records the cut; `make release` publishes. Omit development-only Puma
floor and maintainer pressure tooling from product-facing `CHANGELOG.md`.
